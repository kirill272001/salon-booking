# Salon Booking

A mobile-friendly booking system for a small massage salon: one login screen,
a month calendar and a day view with a column for each specialist.

## Features
- Staff-only access (email + password login)
- Month calendar with a load indicator for every specialist
- Day schedule with free-form start times (e.g. 11:40)
- Procedure list with duration and price
- Overlap protection: a specialist can't be double-booked
- Responsive design, works on phones

## Built with
HTML, CSS, vanilla JavaScript, Supabase (database + auth), Netlify (hosting)
